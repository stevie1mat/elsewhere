# HD scenery assets

All source assets below are CC0 from Poly Haven: https://polyhaven.com/license
Files are served locally. There are no runtime API calls to the asset provider.

- **Kloofendal 48d Partly Cloudy (Pure Sky)**: 8192×4096 tonemapped sky panorama and 1K HDR lighting environment. https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
- **Leafy Grass**: 4K base color, 2K OpenGL normals, 2K packed occlusion/roughness/metallic (roughness uses green). https://polyhaven.com/a/leafy_grass
- **Aerial Asphalt 01**: 4K base color, 2K OpenGL normals and roughness. https://polyhaven.com/a/aerial_asphalt_01
- **Island Tree 01**: textured mesh and 1K material maps, including the leaf alpha mask for cutout foliage. Geometry optimized with meshoptimizer from 1,599,403 to 32,182 triangles; normalized and rendered into a four-angle 2K impostor atlas at runtime. https://polyhaven.com/a/island_tree_01

Downloads were resolved using the public Poly Haven API. Meshoptimizer is MIT licensed; its license is distributed with the npm dependency.
